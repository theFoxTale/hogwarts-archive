# Функциональные требования (+100)

### 1. Структура макета приложения (+5)

- [x] <b>(+5)</b> Страница содержит ровно две основные области: область поиска (вверху) и область результатов (внизу). Обе области визуально различимы и четко разделены.

### 2. Поиск с локальным хранилищем (+15)

- [x] <b>(+5)</b> При загрузке приложения компонент поиска проверяет `localStorage` на наличие сохранённого поискового запроса.
- [x] <b>(+5)</b> Если сохранённый запрос существует, он автоматически отображается в поле ввода.
- [x] <b>(+5)</b> Если сохранённого запроса нет, поле ввода остаётся пустым.

### 3. Отображение результатов поиска (+10)

- [x] <b>(+5)</b> Каждый результат содержит название элемента (имя персонажа).
- [x] <b>(+5)</b> Каждый результат содержит описание элемента (дом, вид, пол или другой набор характеристик).

### 4. Начальная загрузка данных (+10)

- [x] <b>(+5)</b> При начальной загрузке приложение отправляет запрос к API: если в поле поиска есть текст – используется он, иначе запрос возвращает все доступные элементы (первая страница).
- [x] <b>(+5)</b> Полученные данные корректно отображаются в области результатов.

### 5. Выполнение поиска (+20)

- [x] <b>(+5)</b> При нажатии кнопки «Search» лишние пробелы в начале и конце удаляются.
- [x] <b>(+5)</b> Если введённый текст не изменился по сравнению с предыдущим поиском, новый запрос не выполняется.
- [x] <b>(+5)</b> Запрос отправляется на первую страницу результатов.
- [x] <b>(+5)</b> Область результатов обновляется новыми данными.

### 6. Сохранение поискового запроса (+5)

- [x] <b>(+5)</b> При успешном поиске очищенный (trim) поисковый запрос сохраняется в `localStorage`, перезаписывая предыдущее значение.

### 7. Индикация состояния загрузки (+10)

- [x] <b>(+5)</b> Во время выполнения API-запроса отображается индикатор загрузки (спиннер, скелет, текст «Loading…» и т.п.).
- [x] <b>(+5)</b> Индикатор скрывается после получения ответа (или ошибки).

### 8. Обработка ошибок (+10)

- [x] <b>(+5)</b> При ошибке сервера (4xx, 5xx) пользователю показывается понятное сообщение об ошибке.
- [x] <b>(+5)</b> Консоль браузера остаётся чистой (нет неперехваченных ошибок).

### 9. Граница ошибки (Error Boundary) (+15)

- [x] <b>(+5)</b> Присутствует тестовая кнопка, при клике на которую в приложении генерируется ошибка.
- [x] <b>(+5)</b> Ошибка логируется в консоль.
- [x] <b>(+5)</b> Вместо «сломанного» UI отображается запасной интерфейс (fallback UI).
