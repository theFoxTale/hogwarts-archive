### Feature 1: State Management Solution (**35 points**)

- [ ] **(+20)** Redux Toolkit или Zustand интегрированы в приложение.
- [ ] **(+15)** Хранилище состояния (store) правильно настроено и используется для управления состоянием.

### Feature 2: Selected Items Management (**25 points**)

- [ ] **(+15)** Каждый элемент на дашборде имеет чекбокс для выбора.
- [ ] **(+5)** Выбранные элементы хранятся в состоянии и сохраняются при навигации между страницами.
- [ ] **(+5)** Снятие выбора с элемента удаляет его из состояния.

> **Дополнительное поведение кликов** (из описания, но без баллов):
>
> - Клик по чекбоксу только выбирает/снимает выбор, не открывая детали.
> - Клик вне чекбокса на элементе открывает панель деталей, не меняя выбор.
> - Оба действия независимы.

### Feature 3: Flyout Component for Selected Items (**15 points**)

- [ ] **(+5)** Flyout появляется с sticky-позицией внизу страницы, когда выбран хотя бы один элемент.
- [ ] **(+5)** Flyout всегда виден и не исчезает при прокрутке.
- [ ] **(+2)** Flyout отображает количество выбранных элементов.
- [ ] **(+3)** Кнопка «Unselect all» снимает выбор со всех элементов, кнопка «Download» запускает скачивание CSV.

### Feature 4: Downloading Selected Items as CSV (**10 points**)

- [ ] **(+5)** Скачивание реализовано с использованием нативных браузерных API (`Blob`, `URL.createObjectURL`, `a.download`).
- [ ] **(+3)** CSV-файл содержит название (name), описание (description), URL деталей (details URL) и другую полезную информацию.
- [ ] **(+2)** Имя файла отражает количество выбранных элементов (например, `15_items.csv`).

### Feature 5: Theme Selection with Context API (**15 points**)

- [ ] **(+8)** Переключение темы реализовано с использованием Context API.
- [ ] **(+5)** Тема влияет на внешний вид всего приложения.
- [ ] **(+2)** Элемент управления выбором темы (кнопка, переключатель или выпадающий список) находится в верхней части приложения.
